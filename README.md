# QuickNotes

QuickNotes is a small note-taking web app built with plain HTML, CSS and JavaScript. You can write short notes, put them in a category (Personal, Work or Study), search through them and delete the ones you no longer need. Your notes are saved in the browser, so they are still there after you refresh the page.

## Features

- Add a note (up to 200 characters) with a category
- Categories: Personal, Work and Study, each with its own colour
- Delete any note
- Search notes as you type (not case-sensitive)
- Validation messages for empty or too-long notes
- Note counter ("You have no notes yet.", "You have 1 note.", "You have N notes.")
- Notes saved with localStorage
- "Clear all" button with a confirmation (bonus)
- Responsive layout for small screens

## How to run locally

1. Clone the repository: `git clone https://github.com/your-codebyjamiilah/quicknotes-app.git`
2. Open the `quicknotes-app` folder.
3. Double-click `index.html` to open it in your browser (no installation needed).
